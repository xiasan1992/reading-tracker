# 阅读追踪 (Reading Tracker)

Obsidian 插件：按阅读顺序自动记录每天阅读的笔记摘要。

## 工作原理

- 监听笔记切换事件，记录每篇被读笔记的标题、打开时间、停留时长、正文摘要片段。
- 只有停留超过阈值（默认 15 秒）才算"已读"并写入日志，快速跳转自动过滤。
- 失焦期间不累加停留时间，避免"挂着没看"被计入。
- 同一篇笔记当天多次阅读，每次各追加一段，保留阅读顺序。

## 输出

按阅读顺序追加写入：

```
outputs/阅读记录/YYYY-MM-DD.md
```

格式示例：

```markdown
# 阅读记录 2026-07-25

## 1. [[笔记名]] · 09:15 · 2m30s

摘要第一行
摘要第二行

## 2. [[另一篇]] · 09:20 · 1m15s

...
```

## 安装

本仓库源码已编译为 `main.js`，与 `manifest.json` 一并部署到：

```
D:\Document\Obsidian Vault-经史\.obsidian\plugins\reading-tracker\
```

在 Obsidian 中：设置 → 第三方插件 → 关闭"安全模式" → 启用「阅读追踪」。

## 构建

```bash
npm install
npm run build      # tsc 类型检查 + esbuild 打包 -> main.js
```

重新构建后，把 `main.js` 与 `manifest.json` 复制到上面的插件目录，再在 Obsidian 中重载插件即可。

## 设置项

- 停留阈值（秒，默认 15）
- 摘要行数（默认 5）
- 输出文件夹（默认 `outputs/阅读记录`）
- 排除文件夹（每行一个路径）
- 跳过 frontmatter（默认开）

输出目录自身默认不被追踪，避免日志文件造成自污染。
